# Custom Application Icon

You can drop your custom application and window icon directly into this folder.

### Supported File Names (checked in order of preference):
- `app_icon.png` (Recommended: 256x256 or 512x512 PNG with transparent background)
- `icon.png`
- `app_icon.svg`
- `icon.svg`

### Where this icon is used:
1. **Application Window Title Bar** (both Main Workspace and Render Manager windows)
2. **System Taskbar / Dock**
3. **Alt+Tab Window Switcher**
4. **AppImage bundle and Desktop menu entry** (`gmicvideo.desktop`)

A default placeholder icon (`app_icon.png`) is currently provided. Replace it anytime with your own artwork.
